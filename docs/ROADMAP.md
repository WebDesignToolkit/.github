# Roadmap

- Phase 1: repository foundation and safe contribution rules.
- Phase 2: canonical schema, seeded candidate catalog, local validation.
- Phase 3: reusable skills, MCP reviews, design tokens, agency workflows.
- Phase 4: searchable static website and explicit snapshot synchronization.
- Phase 5: evidence-based review of candidates, documentation depth, and a controlled local discovery pipeline.

Do not label Phase 5 complete without actual hands-on review and license assessment.
