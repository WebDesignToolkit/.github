# Security policy

Do not report exploitable security flaws in public issues. Use GitHub private vulnerability reporting when enabled, or contact an organization maintainer privately.

This organization catalogs third-party projects: inclusion is not a security certification. Review dependencies, configuration, privileges and network access before installing an item.

Never commit credentials, session tokens, cookies, private keys, or user data. Do not execute downloaded scripts while evaluating entries. Do not deploy crawlers or persistent automation through GitHub Actions.
