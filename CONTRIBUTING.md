# Contributing to WebDesignToolkit

We welcome useful open-source resources for web design and site building.

1. Search catalog first to prevent duplicate records.
2. Propose a GitHub repository or authoritative project URL, why it helps, and the relevant category.
3. Include the upstream license URL (or mark unknown), recent maintenance evidence, limitations, and supported environments.
4. Start entries as "candidate"; metadata lookup alone does not count as a full review.
5. Do not copy upstream documentation, images, trademarks, or licensed source into this org.
6. Run catalog validation and, when making an approved website update, explicit catalog sync.
7. Follow [AGENTS.md](./AGENTS.md) and [SECURITY.md](./SECURITY.md). No GitHub Actions.

Review gates: source identity, license status, maintenance, functional relevance, security notes, and honest claims. Report fixes via issues or pull requests.
